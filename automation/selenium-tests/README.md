# Selenium WebDriver Test Suite (Python)

Automated browser testing using **Selenium WebDriver (Python)** demonstrating explicit waits (`WebDriverWait`), headless Chrome configuration, and assertion checks.

## How to Run
```bash
# Setup virtual environment & dependencies
python3 -m venv venv
source venv/bin/activate
pip install selenium

# Execute tests
python selenium_form_test.py
```
